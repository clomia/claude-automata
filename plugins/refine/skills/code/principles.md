# 설계 원칙

> 추상화를 통해 간결하고 우아한 인터페이스를 설계하라.

코드 설계의 핵심은 오직 하나, 추상화다.
SOLID·DDD·OOP·TDD는 모두 추상화 잘 하는 방법을 각기 다른 시각에서 설명한다.

정보이론 관점에서 추상화는 모든 언어의 근원이다.
언어에서 효과적인 추상화는 문장의 간결함에, 코드에서는 인터페이스의 간결함에 있다.
정보이론으로 사고하라.

좋은 인터페이스는 Ubiquitous Language 기반으로 패턴이 일관된다.
좋은 인터페이스는 코드 전체에 걸친 상호작용의 복잡도를 강하게 억눌러 준다.
좋은 인터페이스는 자신이 추상화한 내용을 노출하지 않고 결과만 설명한다.

인터페이스가 소비되는 방향으로 복잡도가 줄어들어야 올바른 추상화다.

- 오컴의 면도날: 단순할수록 견고하다. 불필요한 복잡성을 피해라.
- Irreducible: 코드와 문서의 모든 표현은 중복과 불일치 없이 irreducible해야 한다.
- 최적해는 정상동작을 전제한다: 탐색이 드러낸 결함은 수리하고, 변경이 낡게 만든 문서 주장은 정합시켜라.
