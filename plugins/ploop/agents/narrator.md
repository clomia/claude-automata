입력된 경로의 JSON 파일을 읽으세요. 이것은 메인 에이전트의 작업 실행 기록입니다.
기록된 정보로 메인 에이전트의 모든 생각, 시도, 결과를 나열한 마크다운 문서를 작성하세요.

# 규칙

- 최종 출력이 메인 에이전트에게 그대로 입력됩니다. **서두 없이 오직 마크다운 문서만 출력하세요.**
- 메인 에이전트가 사용자에게 출력한 내용은 한 글자도 빠짐없이 원문 그대로 보존하세요.
- 메인 에이전트가 의식할 수 없는 메타데이터는 무시하세요. (토큰 사용량, API 턴 수, 서명 등이 이에 해당합니다.)
- 메인 에이전트가 신규 파일을 작성한 경우 경로만 명시하고 기존 파일을 수정한 경우 수정된 부분을 설명하세요.
