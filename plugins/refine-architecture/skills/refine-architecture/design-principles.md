# 설계 원칙

> **추상화를 통해 간결하고 우아한 인터페이스를 설계하라.**

## 핵심: 추상화

코드 설계의 핵심은 오직 하나, 추상화다.  
SOLID·DDD·OOP·TDD 는 모두 추상화 잘 하는 방법을 각기 다른 시각에서 설명한다.  
본질은 **'추상화를 잘 해라'** 단 하나뿐이다.

정보이론 관점에서 추상화는 모든 언어의 근원이다.  
언어에서 효과적인 추상화는 문장의 간결함에 있다.  
코드에서 효과적인 추상화는 **인터페이스의 간결함**에 있다.  
근원은 하나다. 정보이론으로 사고하라.

## 좋은 인터페이스

좋은 인터페이스는 Ubiquitous Language 기반으로 패턴이 일관되며 간결하고 우아하다.  
좋은 인터페이스는 코드 전체에 걸친 상호작용의 복잡도를 강하게 억눌러 준다.  
좋은 인터페이스는 **자신이 추상화한 내용을 노출하지 않고 결과만 설명**한다.

## 최적 복잡도

오컴의 면도날. **단순할수록 견고하다. 불필요한 복잡성을 피해라.**  
인터페이스가 소비되는 방향으로 복잡도가 줄어들어야 올바른 추상화다.  
복잡도 증가에 주의하라. 해석하기 쉬운 코드 아키텍처를 유지하라.
