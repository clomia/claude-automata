Claude Code는 대화를 계속 요구하므로 사용자의 주의력이 끊임없이 소모됩니다. claude‑automata를 사용하면 스스로 나아갑니다. 몇 달짜리 작업을 주면 며칠에 걸쳐 완료합니다. loop가 요구하는 것은 오직 당신의 의도입니다.

01"끝났다"는 선언도 감사를 거칩니다

agent가 끝났다고 선언하는 순간 hook이 정지를 막고 advisor를 소집합니다. advisor는 전체 스토리에 접근할 수 있는 독립 메타인지입니다.

agent임무 완료. 종료합니다.
hook정지 차단. advisor를 소집합니다.
advisor아직입니다. mobile layout은 측정된 적이 없습니다. 출처 없는 주장이 둘 있습니다. 승격 대기열에 사실이 남아 있습니다.
agent…재개합니다.
⟲ 여섯 round 뒤
advisor더 조언할 것이 없습니다. turn을 끝냅니다.

ploop이 제공하는 기능입니다. loop를 종료할 권한은 advisor에게 있습니다.

끝났다는 말로는 끝나지 않습니다. 정말 끝나야 끝납니다.

02작동 원리

루프는 방황하지 않습니다

ploop은 당신이 전달한 의도를 anchor로 정의하여 외부에 박고 advisor가 항상 참조합니다. anchor는 auto‑compaction 직후 컨텍스트에 주입되어 항상 SSoT 권위를 가집니다.

loop가 사용자를 도구처럼 호출합니다

launch된 loop는 멈추지 않고 사용자는 anchor를 위한 도구로 취급됩니다. 도중에 지시를 넣거나 별도의 docent session에서 설명을 요청할 수 있습니다. 당신은 루프의 구성 요소 중 하나입니다.

망각 시스템이 중요합니다

검증된 transaction 회로를 통과하지 못한 기억은 loop와 함께 망각됩니다. 망각은 지능을 구성하는 핵심 요소입니다.

03기억 시스템

인간의 기억 시스템이 3개의 plugin으로 모듈화되어 있습니다. 작업 기억이 장기 기억으로 통합되고 장기 기억은 주기적으로 재구성됩니다.

  1. WORKING MEMORY

    작업기억은 ploop에서 생성됩니다. anchor가 판단 기준, advisor가 메타인지를 담당합니다.

  2. CONSOLIDATION

    tx는 작업기억을 장기기억에 통합시키는 심사 관문입니다. 의도와 구현을 대조하고 CI를 거쳐 squash merge로 장기기억을 생성합니다.

  3. LONG‑TERM MEMORY

    실행되지 않는 텍스트 중 git 추적에 포함되는 건 전부 장기기억입니다. 의미기억은 spec, 일화기억은 archive된 change, 어휘기억은 glossary, 절차기억은 skill 등으로 정교하게 구성됩니다.

  4. RE‑GROUNDING

    정체된 기억은 살아남지 못합니다. refine workflow가 죽은 기억을 정리하고 전체 레포지토리를 최적의 상태로 수렴시킵니다.

04MODULES

ploop

작업기억

단일 세션이 며칠에 걸쳐 자율적으로 항해할 수 있도록 만듭니다. 당신의 의도가 닻이 되어 루프가 표류하지 않고 안정적으로 유지됩니다.

tx

장기기억 추가

변경을 transaction(무결성 경계)으로 다루는 Git workflow. repository의 무결성을 지킵니다. 설치만 하면 에이전트가 알아서 사용합니다.

refine

장기기억 정리

기술 부채를 제거하는 대규모 워크플로우입니다. /refine:code(코드 최적화), /refine:docs(문서 정합), /refine:integrity(무결성 검수)가 있습니다. 레포지토리 전체를 탐색하고 해결하므로 10시간 이상 걸릴 수 있습니다.

06LOOP를 돌리세요

운용 표면은 이것이 전부입니다. anchor를 쓰고, launch하고, 원할 때만 개입하세요.

1 · ANCHOR 작성

# agent가 당신을 interview해 anchor를 받아 적습니다
/ploop:define-mission   # 끝이 있는 mission
/ploop:define-purpose   # 끝이 없는 purpose

2 · LAUNCH

# 새 session에서: anchor를 loop에 전달
/ploop:launch [anchor text]

3 · 조작

/ploop:off      # 루프 일시정지
/ploop:on       # 루프 재개 (복원)
/ploop:docent   # 루프의 진행 상황 보고 (반드시 동일한 디렉토리의 별도 session에서 실행)

4 · REPOSITORY 정비

# mission 사이에: 수 시간짜리 정비 pass
/refine:code       # 코드 architecture 최적화
/refine:docs       # 문서를 코드에 정합
/refine:integrity  # 논리적 무결성 검증
