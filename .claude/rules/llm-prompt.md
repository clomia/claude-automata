정보이론으로 사고하라. 정보량은 내용이 아닌 맥락에 있다.  

Irreducible: 
- 지시를 추가하는 것보다 생략하는게 더 중요하다. 
  - 생략된 정보 기반으로 암묵적인 지시를 구성할 수 있다.
- 복잡한 설명 없이 명확하게 핵심 정보와 요구사항만 나열.

에이전트의 맥락을 토대로 프롬프트를 구성해라.
구체적인 지시는 에이전트의 사고력을 제한한다.
장황한 지시는 에이전트의 False assumption만 늘린다.
